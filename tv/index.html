功能

v0.5.0 全部功能，专为电视遥控器和沙发场景打磨

遥控器
遥控器原生导航
D-pad 方向键移动焦点，OK 键模拟点击，虚拟光标浏览任意网页——再也不用接鼠标。
浏览
多标签页
顶部标签栏，多页面同时开，随手切换、随手关闭。
输入
语音搜索
遥控器麦克风说话即搜，中文识别，省去一个个选字母的痛苦。
清爽
去广告
内置广告域名拦截，浏览时自动过滤弹窗和横幅广告。
文件
下载管理
网页里的视频、文件一键下载，走系统下载器，通知栏看进度。
大屏
投屏推送
手机上看到一半的视频，一键推到电视上自动全屏播放。
音频
后台音频
切出页面声音继续播，通知栏可暂停、关闭，听播客、听小说都行。
内容
视频源
开放的视频源框架：贴 JSON 配置即可加源，内置 TMDB 热门（需自填 Key），只收合法源。
手机
手机伴侣
同一 Wi-Fi 下扫码配对，手机秒变遥控器：方向键、文字输入、网址一键推送。
收藏
书签收藏
常用网站一键收藏，浏览历史随时找回，首页直达。

安装

适用于 Android TV / Google TV（海信 VIDAA 系统暂不支持）

1

下载 APK

在本页点击下载按钮获取 jizai-tv-browser.apk。

2

传到电视

用 U 盘拷贝，或通过局域网把 APK 传到电视上。

3

允许安装未知应用

电视进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给文件管理器开启权限。

4

打开

用文件管理器找到 APK 点击安装，完成后在应用列表打开「鸡仔浏览器」。
